# Godot Engine — Version Reference

| Field | Value |
|-------|-------|
| **Engine Version** | Godot 4.3 (Godot 4.x Architecture) |
| **Language Support** | GDScript 2.0 (typed) & C# (.NET 8.0) |
| **Rendering** | Forward+, Mobile, Compatibility (OpenGL ES 3.0) |
| **GDExtension** | Native C++ / Rust bindings support |

## Key Capabilities & Best Practices

- Godot 4 Node & Scene tree architecture with strong static typing (`@export`, `@onready`).
- Signal-driven decoupled communication.
- CharacterBody2D / CharacterBody3D physics handling.
- Multi-threaded rendering and physics servers.

# Godot - UI

## Nodos Control
La base de todas las interfaces de usuario. Usar anclas (anchors) para diseño responsivo.

## Theme Overrides
En lugar de crear múltiples nodos para variaciones pequeñas, utilizar Theme Overrides para cambiar fuentes, colores y estilos visuales específicos desde el inspector.

## Contenedores
Usar `HBoxContainer`, `VBoxContainer`, `GridContainer` y `MarginContainer` para crear interfaces escalables sin posicionar píxeles a mano.

# Unity - UI

## UI Toolkit vs UGUI Canvas
- UGUI sigue siendo válido pero UI Toolkit es el estándar futuro. UI Toolkit ofrece mejor rendimiento para interfaces complejas sin el costo de actualizar jerarquías completas de GameObjects.

## Estilizado con USS/UXML
- UI Toolkit separa la estructura (UXML) del estilo (USS), adoptando convenciones familiares para los desarrolladores web. Esto facilita el mantenimiento del diseño y reuso en herramientas del editor y runtime.

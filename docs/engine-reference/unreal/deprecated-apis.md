# Unreal Engine APIs Deprecadas

- El módulo legacy de PhysX ya no puede ser habilitado ni utilizado desde Unreal Engine 5.1+.
- Componentes antiguos de UI y macros de UPROPERTY que han cambiado en los últimos releases a favor del macro `UPROPERTY(EditAnywhere, BlueprintReadWrite)`.
- El uso directo de Axis Mappings en C++ sin el Enhanced Input Plugin se considera una práctica obsoleta.

# Unreal Engine - UI

## CommonUI vs Standard UMG
- El plugin CommonUI expande el UMG clásico, facilitando inmensamente el manejo de foco de consola, historial de navegación atrás (stacking) y plataformas múltiples. Altamente recomendado para menús complejos.

## Input Routing
- CommonUI soluciona el clásico problema de "Foco robado" manejando de forma exclusiva quién recibe los eventos de input según la jerarquía de los menús activos.

## Styling Data Assets
- Separar el estilo (fuentes, botones, márgenes) en Data Assets para mantener una coherencia visual y hacer cambios masivos a toda la UI sin editar decenas de widgets individuales.

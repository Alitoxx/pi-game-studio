# Settings Guidance

Provides advisory presets and change triggers for configuring a Pi Game Studio project.

## Advisory Presets
- **Early prototyping**: Use `modes.rigor: low`, `modes.automation: autonomous`.
- **Vertical Slice / Production**: Switch to `modes.rigor: high`, `modes.automation: guided`.
- **Release**: Use `modes.rigor: strict`, `modes.automation: collaborative`.

## Change Triggers
Use this guidance to suggest settings changes based on the project's current lifecycle stage or situation.

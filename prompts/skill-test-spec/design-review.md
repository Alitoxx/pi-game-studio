# Design Review Skill Test Spec

## Overview
This specification details the expected behavior and test cases for the `design-review` skill.

## Objectives
- Review design specifications and alignment
- Ensure GDDs and specs are complete and coherent
- Flag missing components or contradictions

## Test Cases
1. **Pass condition**: The design doc follows the template and contains all required sections without internal contradictions.
2. **Fail condition**: Incomplete sections or conflicting statements in the design doc.

# Gate Check Skill Test Spec

## Overview
This specification details the expected behavior and test cases for the `gate-check` skill.

## Objectives
- Validate gate readiness before production
- Ensure all criteria for the specified gate are met
- Report clear pass/fail status and missing requirements

## Test Cases
1. **Pass condition**: All required docs and code states meet the gate criteria.
2. **Fail condition**: Missing required docs or failed tests.

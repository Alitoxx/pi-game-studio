# Pi Game Studio — UE5 Third Person Starter

## Requisitos
- Unreal Engine 5.4+
- Visual Studio 2022 o Xcode

## Instrucciones de Instalación
1. Generar los archivos del proyecto (Generate Visual Studio / Xcode project files).
2. Abrir el archivo `Game.uproject` en Unreal Editor.

## Estructura del Proyecto
- `Source/Game/`: Código fuente de C++ del proyecto, incluyendo el personaje y el modo de juego.
- `Config/`: Archivos de configuración predeterminados para el motor y las entradas.

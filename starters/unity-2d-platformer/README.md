# Pi Game Studio — Unity 2D Platformer Starter

## Requisitos
- Unity 2022.3+ LTS
- .NET SDK

## Instrucciones de Instalación
1. Abrir en Unity Hub.
2. Instalar el paquete Input System a través del Package Manager (si no está instalado).

## Cómo Ejecutar
- Abre la escena `Main` en la carpeta Scenes.
- Presiona Play.

## Estructura del Proyecto
- `Assets/Scripts/`: Contiene los scripts principales como `PlayerController` y `GameManager`.
- `Packages/`: Manifiesto de paquetes de Unity.
- `ProjectSettings/`: Configuraciones básicas del proyecto.
